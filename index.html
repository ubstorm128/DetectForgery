How It Works
A seamless, three-step forensic pipeline providing immediate insights into document authenticity.
1

Upload & Align

Upload a document. The system detects the document type, aligns it geometrically, and extracts text via intelligent OCR.

2

Forensic Analysis

Advanced checks including Error Level Analysis (ELA) and ORB Copy-Move detection run in parallel to find manipulations.

3

Authenticity Score

Receive a comprehensive Authenticity Score, categorized risk levels, and visual bounding boxes highlighting anomalies.

Enterprise-Grade Tamper Detection

Veristamp leverages multiple forensic signals to prevent fraudulent identity documents from bypassing security protocols.

  • ✓ Error Level Analysis (ELA) detects spliced elements.
  • ✓ Geometric and Font Consistency OCR checks.
  • ✓ Copy-Move Detection for cloned data.
  • ✓ Dual-side cross-verification for smart cards.
Important: Veristamp analyzes images for digital manipulation. It supplements security checks but is not a substitute for official government validation APIs (e.g. UIDAI).
